Entry for the make.fun bounty **u-mfnakmal-dad-joke-showdown-1d2ce3e5**
("Dad Joke Showdown"): tell one dad joke, at most 200 characters. The groanier
the better.

## The joke

> My wife was drawing her eyebrows on way too high. I said so and she looked surprised.

`main.py` writes the joke to `/output/entry.txt`.

## Run

```bash
python3 main.py
cat /output/entry.txt
```

Standard library only, no network, no model calls.
